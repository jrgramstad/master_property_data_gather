🏠 Property Master Data Import

ClickUp → Supabase Migration Tool

⚠️ One-time migration tool - Updates existing properties only

Instructions

  1. Export your property data from ClickUp as CSV
  2. Upload the CSV file below
  3. Click "Import Data" to process
  4. Review the results and handle any unmatched properties
📋 Expected CSV Columns (click to expand)

Your CSV should include these columns:

  • Task Name (property address)
  • Status, Bedrooms, Bathrooms, Square Footage
  • Year of house, Zillow Value, Acquisition Cost
  • Date Acquired, Acquisition Method
  • Fair Market Rent, Monthly Payment, Mortgage Balance
  • Interest Rate, Department In Charge
  • Foundation Type, Garage Spaces, Gas/Water/Stove Type
  • Checkboxes: Deck/Porch, Dining Room, Family Room, etc.
  • Lockbox Code, TTCU #, Refi Bank
